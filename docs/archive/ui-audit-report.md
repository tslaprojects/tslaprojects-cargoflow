# CargoFlow — UI/UX аудит

Метод: чтение кода (`src/app`, `src/components`, `src/features`, `globals.css`), скриншоты 25 экранов на 1440 и 390 px
от лица 5 ролей (демо-данные seed), правила skill **UI/UX Pro Max** (приоритеты: доступность → касания → производительность →
стиль → раскладка → типографика/цвет → анимация → формы → навигация → данные) и его дизайн-направление для
`logistics operations console` c `--density 8 --motion 3`: **Minimalism & Swiss Style**, navy + trust blue.

## Найденные проблемы

### Critical / High

1. **Шрифт не загружается.** `--font-sans: "Inter"` без `next/font`/`@font-face` → системный шрифт (на Linux — DejaVu): широкий,
   «грубый», таблицы и KPI теряют плотность. Plus Jakarta Sans, которую предлагает skill, не содержит базовой кириллицы
   (только `cyrillic-ext`) — выбран Inter (кириллица, табличные цифры, вариативный).
2. **Motion-системы нет.** Классы `animate-in`/`fade-in-0` в диалоге без плагина не работают; Sheet, Dropdown, Tooltip, Tabs,
   тосты появляются мгновенно; нет длительностей/кривых, нет `prefers-reduced-motion`.
3. **Этапы перевозки противоречат сами себе.** После таможни статус снова `IN_TRANSIT`, и шкала показывает текущим «В пути»,
   а ниже — уже пройденные «Граница», «Таможня» (`order-status-timeline.tsx` берёт индекс текущего статуса, а не
   максимального достигнутого этапа).
4. **Карточка перевозки не отвечает «где груз и когда будет».** Карта и последняя позиция спрятаны во вкладке «Маршрут»;
   в «Что дальше» у заказчика при движении видны только «Открыть спор» и «Отменить» (опасные действия как главные);
   сводка справа дублирует шапку (статус, маршрут).
5. **Dashboard: главное не на первом месте.** «Требуют вашего действия» — в правой колонке ниже KPI; таблица последних
   перевозок обрезается справа (колонка «ОБ…» уходит в скрытый скролл на 1440 px); вторая строка KPI («Грузов», «Ставок»,
   «В споре 0») оторвана от первой.
6. **Мобильная навигация обрезает подписи** («Мои пере…», «Создать г…»): в нижнем меню длинные названия; пункты без
   коротких подписей.

### Medium

7. **Фильтры перегружают экран.** Биржа — 12 полей сразу (≈280 px над контентом); на мобильном список перевозок начинается
   только со второго экрана. Нужны основные фильтры + «Ещё фильтры», на мобильном — фильтры в панели.
8. **Карточка груза.** Название обрезается до 2–3 слов; бейдж «Опубликован» на каждой карточке биржи — шум (все
   опубликованы); цена — главный для перевозчика параметр — внизу.
9. **Радиусы без системы:** `rounded-lg` ×53, `rounded-xl` ×49, `rounded-md` ×22, `rounded-2xl` ×12 — кнопки 8 px,
   карточки 14 px, KPI-иконки 10 px, мобильные панели 16 px без правила.
10. **Цвета вне токенов** в 13 файлах (`bg-slate-*`, `hover:bg-red-700`, `hover:bg-green-800`, `fill-amber-400`) — нет
    `--*-hover` токенов для danger/success, оттенки KPI заданы вручную.
11. **Скелетоны не повторяют структуру** экранов (одинаковый `PageSkeleton` для всех разделов, без shimmer и reduced-motion).
12. ~~Мастер создания груза: липкая панель перекрывает «Добавить точку»~~ — проверено в коде: артефакт полностраничного
    скриншота (sticky-панель в конце формы, при прокрутке кнопка доступна). Не проблема.
13. **Сайдбар** — плоский список до 11 пунктов без групп; «MVP · ru-RU · Asia/Almaty» — служебный текст в интерфейсе.

### Low

14. Карточки на мобильном повторяют подписи «Маршрут / Статус / Сумма» в каждой строке.
15. Нет единых токенов теней, z-index и ширины контента (контейнер 1400 px задан строкой в `AppShell`).
16. Тёмной темы нет (токены готовы только для светлой) — отложено: требует прохода по всем 50 экранам.

## Что уже хорошо (сохраняем)

- Единый реестр статусов `StatusBadge` (цвет + иконка + текст, не только цвет).
- Семантические цветовые токены success/warning/info/danger/neutral.
- Skip-link, `aria-current` в навигации, `role="alert"` у ошибок, видимый фокус.
- Нет горизонтального переполнения ни на одном из 50 проверенных экранов.
- Мобильный экран водителя: крупные кнопки, одно следующее действие.

## Что исправлено (редизайн)

| #   | Проблема                 | Решение                                                                                                                                                                                 |
| --- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Шрифт не загружался      | Inter Variable через `@fontsource-variable/inter` (кириллица, файлы в сборке)                                                                                                           |
| 2   | Нет motion-системы       | токены длительностей/кривых, 18 keyframes, анимации Radix-состояний, `template.tsx`-переходы, `prefers-reduced-motion`                                                                  |
| 3   | Противоречивые этапы     | `lib/state-machine/order-progress.ts` (монотонный прогресс, 7 unit-тестов), новая шкала этапов                                                                                          |
| 4   | «Где груз и когда будет» | `OrderTrackingHeader`: фаза, прогресс маршрута, последняя позиция и остаток км, плановая доставка с честным предупреждением о просрочке, транспорт, мини-карта; «Связаться» в действиях |
| 5   | Dashboard                | KPI с бизнес-смыслом и ссылками, «Требуют действия» первым блоком, таблица без обрезки                                                                                                  |
| 6   | Мобильное меню           | короткие подписи, счётчик непрочитанных, индикатор активного пункта, safe-area                                                                                                          |
| 7   | Фильтры                  | прогрессивное раскрытие «Фильтры (n)», на мобильном свёрнуты                                                                                                                            |
| 8   | Карточка груза           | маршрут и цена первыми, название в 2 строки, без шумного «Опубликован»                                                                                                                  |
| 9   | Радиусы                  | шкала sm/md/lg/xl/2xl с правилами использования                                                                                                                                         |
| 10  | Цвета вне токенов        | 0 «сырых» цветов палитры в `src/app`, `src/components`, `src/features`                                                                                                                  |
| 11  | Скелетоны                | по структуре (`list`/`detail`/`dashboard`), шиммер, маршрутные `loading.tsx`                                                                                                            |
| 13  | Сайдбар                  | группы разделов, сворачивание до иконок (cookie, без сдвига раскладки)                                                                                                                  |
| 14  | Повтор подписей          | `DataTable`: статус — бейджем в заголовке карточки, маршрут — на всю ширину                                                                                                             |
| 15  | Контейнеры/тени          | токены `max-w-page/form/prose`, шкала теней по уровням                                                                                                                                  |

Найдено и исправлено попутно: `MapView` применял размеры к холсту, который MapLibre переопределяет
(`.maplibregl-map { position: relative }`) — размеры теперь задаются внешнему блоку.
